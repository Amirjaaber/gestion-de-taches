# Gestion des tâches

Petite application Python en console pour gérer des tâches quotidiennes.
Projet réalisé dans le cadre du module **Outils collaboratifs avec Git / GitHub** (Licence 1, S1).

## Fonctionnalités

- **Ajouter une tâche** : on saisit un titre, la saisie vide est refusée.
- **Afficher les tâches** : toutes les tâches avec leur numéro, avec un message si la liste est vide.
- **Quitter** : ferme le programme (une option invalide affiche un message d'erreur).

## Étapes réalisées

1. Création du fichier `main.py` avec le menu, l'ajout et l'affichage des tâches.
2. Test du programme avec le bouton **Run Python File** de VS Code.
3. Initialisation du dépôt Git local et premiers commits.
4. Publication du projet sur GitHub.

## Comment exécuter le programme

1. Ouvrir le dossier du projet dans **VS Code** (menu *Fichier > Ouvrir le dossier*).
2. Ouvrir le fichier `main.py`.
3. Cliquer sur le bouton **▶ Run Python File** en haut à droite de VS Code.
4. Le programme s'exécute dans le terminal : il suffit de choisir une option du menu.

Le programme utilise seulement les notions de base de Python (variables, liste, conditions, boucle `while` et quelques fonctions). Aucune base de données ni interface graphique.
